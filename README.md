# Wesly — Finance & Credit Portfolio

A responsive, animated personal portfolio website designed for a finance / credit-analysis profile.

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.

## Before publishing
Search `index.html` for square-bracket placeholders such as `[Credit Officer]`, `[TCS]`, and `[MBA]`, and replace them with verified information.
- Replace the sample email `kevinwesly35.com`.
- Replace the LinkedIn homepage link with your actual profile URL.
- Remove any skills you cannot confidently discuss in an interview.
- The three project cards are **suggested project ideas**, not claims of completed work. Build each project before presenting it as completed, or rename the section to “Projects I’m Building”.
- Update the meta description and page title if your focus changes.

## Free hosting with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a new public repository (for example, `wesly-portfolio`).
3. Upload `index.html`, `styles.css`, `script.js`, and this README.
4. In the repository, open **Settings → Pages**.
5. Under build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. After GitHub Pages publishes it, copy the generated website URL into your resume.

No build tools or paid hosting are required. Google Fonts requires an internet connection; the site remains usable with fallback fonts if it cannot load.
